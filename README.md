# 🛒 Aplikasi Kasir

Aplikasi Kasir berbasis **Laravel** untuk membantu mengelola produk, kategori, stok, dan transaksi penjualan.

Project ini dibuat sebagai aplikasi **Point of Sale (POS)** sederhana yang dapat digunakan untuk membantu proses penjualan dan pengelolaan data produk.

## ✨ Fitur

- 🔐 Login pengguna
- 📦 Manajemen produk
- 🏷️ Manajemen kategori
- 📊 Manajemen stok
- 🛒 Sistem order / kasir
- ➕ Tambah produk ke keranjang
- ➖ Mengatur jumlah produk
- 🗑️ Menghapus produk dari keranjang
- 💰 Perhitungan total pembayaran
- 💵 Perhitungan uang bayar dan kembalian
- 🧾 Transaksi penjualan
- 🔎 Pencarian produk
- 📱 Tampilan responsif
